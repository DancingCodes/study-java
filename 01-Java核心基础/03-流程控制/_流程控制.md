# 流程控制

程序默认从上往下一行一行执行。流程控制就是让程序能**做判断**和**重复执行**。

## 一、条件判断

### if / else if / else

```java
int score = 85;

if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
```

执行逻辑：
- 从上往下依次判断条件
- 哪个条件先满足就执行哪个分支，**后面的不再判断**
- 都不满足就走 else（else 可以不写）

### switch（多分支选择）

```java
int day = 3;

switch (day) {
    case 1:
        System.out.println("星期一");
        break;
    case 2:
        System.out.println("星期二");
        break;
    case 3:
        System.out.println("星期三");
        break;
    default:
        System.out.println("其他");
}
```

注意：
- 每个 case 后面要写 `break`，否则会**穿透**到下一个 case 继续执行
- `default` 相当于 else，都不匹配时执行
- switch 支持的类型：`int`、`char`、`String`、`enum`（不支持 long、float、double）

### switch 的穿透问题

```java
int day = 2;

switch (day) {
    case 1:
        System.out.println("星期一");
    case 2:
        System.out.println("星期二");  // 匹配这里
    case 3:
        System.out.println("星期三");  // 没有 break，继续执行！
    default:
        System.out.println("其他");    // 也执行了！
}
// 输出：星期二、星期三、其他（全部穿透了）
```

### Java 14+ 新写法（箭头语法，不会穿透）

```java
int day = 3;

switch (day) {
    case 1 -> System.out.println("星期一");
    case 2 -> System.out.println("星期二");
    case 3 -> System.out.println("星期三");
    default -> System.out.println("其他");
}
```

箭头 `->` 写法不需要 break，不会穿透，推荐使用。

### if vs switch 怎么选？

| 场景 | 用什么 |
|------|--------|
| 判断范围（大于、小于、区间） | if |
| 判断固定值（等于某几个值） | switch |
| 条件复杂（&&、\|\|） | if |

## 二、循环

### for 循环（知道循环几次时用）

```java
// 打印 1 到 5
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```

三个部分：
```
for (初始化; 条件; 更新) {
    循环体
}
```
- **初始化**：`int i = 1`，只执行一次
- **条件**：`i <= 5`，每次循环前判断，false 就退出
- **更新**：`i++`，每次循环体执行完后执行

### while 循环（不知道循环几次时用）

```java
int count = 0;

while (count < 3) {
    System.out.println("count = " + count);
    count++;
}
```

- 先判断条件，再执行循环体
- 条件为 false 时不执行，可能**一次都不执行**

### do-while 循环（至少执行一次）

```java
int count = 10;

do {
    System.out.println("count = " + count);  // 即使条件不满足，也会执行一次
    count++;
} while (count < 3);
```

- 先执行循环体，再判断条件
- **至少执行一次**，这是和 while 唯一的区别
- 实际开发中用得很少

### for vs while 怎么选？

| 场景 | 用什么 |
|------|--------|
| 知道循环次数（遍历数组、固定次数） | for |
| 不知道循环次数（读文件直到结束、等待用户输入） | while |
| 至少要执行一次 | do-while |

## 三、break 和 continue

### break — 立即跳出整个循环

```java
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break;  // 到 5 就停
    }
    System.out.println(i);
}
// 输出：1 2 3 4
```

### continue — 跳过本次，继续下一次循环

```java
for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;  // 跳过 3
    }
    System.out.println(i);
}
// 输出：1 2 4 5
```

### 区别

| | break | continue |
|--|-------|----------|
| 效果 | 直接退出循环 | 跳过本次，继续下一次 |
| 后面的代码 | 不执行 | 不执行本次的，但下一次照常 |

## 四、嵌套循环

```java
// 打印九九乘法表
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print(j + "×" + i + "=" + (i * j) + "\t");
    }
    System.out.println();  // 换行
}
```

- 外层循环执行一次，内层循环执行一轮
- 嵌套层数尽量不超过 2 层，太深了可读性差

- 60-79：及格

要求：用箭头语法 `->` 写。

### 题目 4：跳过 3 的倍数

用 for + continue 实现。
