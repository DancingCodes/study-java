# 方法与递归

## 什么是方法？

方法就是**一段有名字的代码块**，可以反复调用，避免重复写代码。

其他语言叫「函数」，Java 里叫「方法」，是一个意思。

## 方法的定义

```java
修饰符 返回值类型 方法名(参数列表) {
    方法体
    return 返回值;  // 如果是 void 可以不写
}
```

### 示例

```java
// 无参无返回值
public static void sayHello() {
    System.out.println("你好");
}

// 有参有返回值
public static int add(int a, int b) {
    return a + b;
}

// 调用
sayHello();               // 你好
int result = add(3, 5);   // 8
```

### 各部分含义

| 部分 | 含义 |
|------|------|
| `public static` | 修饰符（现阶段固定写法，后面学面向对象会详细讲） |
| `void` / `int` | 返回值类型。void 表示不返回，int 表示返回一个整数 |
| `方法名` | 小驼峰命名，如 `getUserName`、`calculateTotal` |
| `参数列表` | 调用时传入的数据，可以有多个，也可以没有 |
| `return` | 把结果返回给调用者。void 方法可以不写 return |

> **为什么现在要加 static？** 因为 `main` 方法是 static 的，static 方法只能直接调用 static 方法。非 static 方法需要先创建对象才能调用。等学到面向对象之后，大部分方法就不需要加 static 了。

## 方法重载（Overload）

**同一个类中，方法名相同，但参数不同**（个数不同或类型不同），叫方法重载。

```java
public static int add(int a, int b) {
    return a + b;
}

public static double add(double a, double b) {
    return a + b;
}

public static int add(int a, int b, int c) {
    return a + b + c;
}
```

调用时 Java 会根据传入的参数**自动选择**匹配的方法：

```java
add(1, 2);        // 调用第一个：int add(int, int)
add(1.5, 2.5);    // 调用第二个：double add(double, double)
add(1, 2, 3);     // 调用第三个：int add(int, int, int)
```

> **注意**：返回值类型不同**不算**重载。只看方法名 + 参数列表。

## 可变参数

不确定要传多少个参数时，用 `类型... 变量名`：

```java
public static int sum(int... numbers) {
    int total = 0;
    for (int num : numbers) {
        total += num;
    }
    return total;
}

// 传几个都行
sum(1, 2);           // 3
sum(1, 2, 3, 4, 5);  // 15
sum();               // 0
```

注意事项：
- 可变参数本质是**数组**，在方法内部当数组用
- 一个方法最多只能有**一个**可变参数，且必须放在参数列表**最后**

```java
// 对：普通参数在前，可变参数在后
public static void print(String prefix, int... numbers) { }

// 错：可变参数不在最后
// public static void print(int... numbers, String suffix) { }
```

## 值传递（重要概念）

Java 的方法参数传递**只有值传递**，没有引用传递。

### 基本类型：传的是副本，改不了原值

```java
public static void change(int num) {
    num = 100;  // 改的是副本
}

int a = 10;
change(a);
System.out.println(a);  // 还是 10，没变
```

### 引用类型：传的是地址的副本，能改对象内容

```java
public static void changeName(String[] arr) {
    arr[0] = "李四";  // 通过地址改了对象的内容
}

String[] names = {"张三"};
changeName(names);
System.out.println(names[0]);  // 李四，变了！
```

> 简单记：基本类型改不了，引用类型能改内容但不能改引用本身。

## 递归

方法**调用自己**就是递归。

### 两个要素
1. **终止条件**：什么时候停下来（没有的话会无限递归，栈溢出）
2. **递推关系**：怎么把大问题拆成小问题

### 示例 1：阶乘

`5! = 5 × 4 × 3 × 2 × 1 = 120`

```java
public static int factorial(int n) {
    if (n <= 1) return 1;       // 终止条件
    return n * factorial(n - 1); // 递推：n! = n × (n-1)!
}

factorial(5);  // 5 × 4 × 3 × 2 × 1 = 120
```

执行过程：
```
factorial(5)
= 5 × factorial(4)
= 5 × 4 × factorial(3)
= 5 × 4 × 3 × factorial(2)
= 5 × 4 × 3 × 2 × factorial(1)
= 5 × 4 × 3 × 2 × 1
= 120
```

### 示例 2：斐波那契数列

`1, 1, 2, 3, 5, 8, 13, 21...`（每个数 = 前两个数之和）

```java
public static int fib(int n) {
    if (n <= 2) return 1;          // 第 1、2 个数都是 1
    return fib(n - 1) + fib(n - 2); // 递推关系
}

fib(6);  // 8
```

### 递归的缺点

- 层数太深会**栈溢出**（StackOverflowError）
- 重复计算多，效率低（斐波那契递归版非常慢）
- 实际开发中能用循环就用循环，递归主要用来理解思路

## 练习题

### 题目 1：写一个 max 方法
接收两个 int 参数，返回较大的那个。

### 题目 2：方法重载
写三个 `multiply` 方法：
- `multiply(int, int)` → 返回两个整数的乘积
- `multiply(double, double)` → 返回两个小数的乘积
- `multiply(int, int, int)` → 返回三个整数的乘积

分别调用并打印结果。

### 题目 3：可变参数求平均值
写一个 `average` 方法，接收可变参数 `double... numbers`，返回平均值。

### 题目 4：递归求阶乘
写一个 `factorial` 方法，用递归计算 n 的阶乘。打印 `factorial(10)` 的结果。

### 题目 5：递归求和
写一个 `sumTo` 方法，用递归计算 1 + 2 + ... + n。打印 `sumTo(100)` 的结果（应该是 5050）。
