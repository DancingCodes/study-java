# 面向对象基础

## 一、什么是面向对象？

之前写的代码都是「面向过程」——从上到下一步步执行。面向对象换了一种思路：**把数据和操作数据的方法打包成一个整体（对象）**。

现实类比：
- 面向过程：先打开冰箱 → 把大象放进去 → 关上冰箱（关注步骤）
- 面向对象：有一个「冰箱」对象，它有 `open()`、`put(大象)`、`close()` 方法（关注谁来做）

## 二、类和对象

| 概念 | 说明 | 类比 |
|------|------|------|
| **类（Class）** | 模板/图纸，定义有哪些属性和方法 | 汽车设计图 |
| **对象（Object）** | 根据类创建出来的具体实例 | 一辆真实的车 |

一个类可以创建**多个**对象，就像一张图纸可以造很多辆车。

### 定义一个类

```java
public class Dog {
    // 属性（字段）：描述对象有什么
    String name;
    int age;

    // 方法：描述对象能做什么
    public void bark() {
        System.out.println(name + "在汪汪叫");
    }
}
```

### 创建对象并使用

```java
public class Main {
    public static void main(String[] args) {
        Dog dog1 = new Dog();   // 创建第一个对象
        dog1.name = "旺财";
        dog1.age = 3;
        dog1.bark();            // 旺财在汪汪叫

        Dog dog2 = new Dog();   // 创建第二个对象
        dog2.name = "小白";
        dog2.age = 1;
        dog2.bark();            // 小白在汪汪叫
    }
}
```

`new Dog()` 做了什么？
1. 在堆内存中分配空间
2. 给属性赋默认值（String → null，int → 0）
3. 返回对象的内存地址，赋给变量

## 三、构造器（Constructor）

每次 `new` 完还要一个个赋值太麻烦了。**构造器**就是创建对象时自动调用的方法，用来初始化属性。

```java
public class Dog {
    String name;
    int age;

    // 构造器：方法名必须和类名一样，没有返回值类型
    public Dog(String name, int age) {
        this.name = name;   // this.name 是属性，name 是参数
        this.age = age;
    }

    public void bark() {
        System.out.println(name + "在汪汪叫");
    }
}
```

使用：
```java
Dog dog = new Dog("旺财", 3);  // 创建时直接传参
dog.bark();                     // 旺财在汪汪叫
```

### 构造器规则

| 规则 | 说明 |
|------|------|
| 方法名必须和类名相同 | `Dog` 类的构造器就叫 `Dog()` |
| 没有返回值类型 | 连 void 都不写 |
| 不写构造器时，系统提供默认的无参构造器 | `public Dog() {}` |
| 一旦写了有参构造器，默认的无参构造器就没了 | 需要的话要手动加回来 |

### 构造器重载

```java
public class Dog {
    String name;
    int age;

    // 无参构造器
    public Dog() {
        this.name = "无名";
        this.age = 0;
    }

    // 有参构造器
    public Dog(String name, int age) {
        this.name = name;
        this.age = age;
    }
}

// 两种方式都能用
Dog dog1 = new Dog();              // 无名, 0
Dog dog2 = new Dog("旺财", 3);     // 旺财, 3
```

## 四、this 关键字

`this` 指的是**当前对象**。主要用在两个地方：

### 1. 区分属性和参数

```java
public Dog(String name, int age) {
    this.name = name;  // this.name = 属性，name = 参数
    this.age = age;
}
```

如果属性名和参数名不同，可以不写 this，但**推荐统一写**，清晰。

### 2. 在一个构造器里调用另一个构造器

```java
public Dog() {
    this("无名", 0);  // 调用有参构造器，必须放在第一行
}

public Dog(String name, int age) {
    this.name = name;
    this.age = age;
}
```

## 五、封装（Encapsulation）

封装就是：**把属性藏起来，通过方法来访问**。

为什么？直接 `dog.age = -5` 谁都能改，没法控制。

### 步骤

1. 属性用 `private` 修饰（外部不能直接访问）
2. 提供 `getter` / `setter` 方法（可以加校验逻辑）

```java
public class Dog {
    private String name;
    private int age;

    public Dog(String name, int age) {
        this.name = name;
        setAge(age);  // 构造器里也走 setter，保证校验
    }

    // getter：获取属性值
    public String getName() {
        return name;
    }

    // setter：设置属性值（可以加校验）
    public void setAge(int age) {
        if (age < 0 || age > 30) {
            System.out.println("年龄不合法");
            return;
        }
        this.age = age;
    }

    public int getAge() {
        return age;
    }
}
```

```java
Dog dog = new Dog("旺财", 3);
dog.name;          // 报错！private 不能直接访问
dog.getName();     // "旺财"，通过 getter 访问
dog.setAge(-1);    // 年龄不合法（被拦住了）
dog.setAge(5);     // OK
```

### 访问修饰符

| 修饰符 | 本类 | 同包 | 子类 | 其他 |
|--------|------|------|------|------|
| `private` | ✅ | ❌ | ❌ | ❌ |
| （默认/不写） | ✅ | ✅ | ❌ | ❌ |
| `protected` | ✅ | ✅ | ✅ | ❌ |
| `public` | ✅ | ✅ | ✅ | ✅ |

现阶段记住：**属性用 private，方法用 public**。

## 练习

### 练习 1：定义一个 Student 类
属性：`name`（String）、`age`（int）、`score`（double）
- 属性用 private
- 写有参构造器和无参构造器
- 写 getter 和 setter
- setter 中：age 不能小于 0，score 必须在 0-100 之间

### 练习 2：使用 Student 类
在 Main 类的 main 方法中：
- 用有参构造器创建一个学生
- 打印学生信息
- 尝试用 setter 设置非法的 age 和 score，观察校验效果

### 练习 3：定义一个 Calculator 类
写一个计算器类，包含：
- `add(int a, int b)` 返回和
- `subtract(int a, int b)` 返回差
- `multiply(int a, int b)` 返回积
- `divide(int a, int b)` 返回商（注意处理除以 0 的情况）

注意：这些方法**不需要 static**，通过 `new Calculator()` 创建对象来调用。
