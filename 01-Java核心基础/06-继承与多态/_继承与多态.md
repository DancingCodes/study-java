# 继承与多态

## 一、继承（Inheritance）

### 为什么需要继承？

假设你要定义 `Dog` 和 `Cat` 两个类，它们都有 `name`、`age` 属性和 `eat()` 方法。每个类都写一遍？太重复了。

继承的思路：**把共同的部分抽到一个父类里，子类自动拥有父类的属性和方法**。

### 语法

```java
// 父类（也叫基类、超类）
public class Animal {
    private String name;
    private int age;

    public Animal(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void eat() {
        System.out.println(name + "在吃东西");
    }

    public String getName() {
        return name;
    }

    public int getAge() {
        return age;
    }
}

// 子类用 extends 继承父类
public class Dog extends Animal {
    public Dog(String name, int age) {
        super(name, age);  // 调用父类构造器
    }

    public void bark() {
        System.out.println(getName() + "在汪汪叫");
    }
}

public class Cat extends Animal {
    public Cat(String name, int age) {
        super(name, age);
    }

    public void meow() {
        System.out.println(getName() + "在喵喵叫");
    }
}
```

使用：
```java
Dog dog = new Dog("旺财", 3);
dog.eat();   // 旺财在吃东西（继承自 Animal）
dog.bark();  // 旺财在汪汪叫（Dog 自己的方法）

Cat cat = new Cat("小白", 2);
cat.eat();   // 小白在吃东西
cat.meow();  // 小白在喵喵叫
```

### 继承的核心规则

| 规则 | 说明 |
|------|------|
| Java 只支持**单继承** | 一个类只能 extends 一个父类 |
| 可以多层继承 | A → B → C（C 继承 B，B 继承 A） |
| 子类拥有父类所有属性和方法 | 但 private 的不能直接访问，要通过 getter/setter |
| 所有类的祖宗是 `Object` | 不写 extends 时默认继承 Object |

### 子类构造器必须调用父类构造器（易错点）

子类创建对象时，**必须先初始化父类部分**。规则如下：

1. 如果父类有无参构造器，子类构造器会**自动**调用 `super()`，你可以不写
2. 如果父类**只有有参构造器**（没有无参构造器），子类**必须**显式写 `super(参数)`，否则编译报错
3. 如果你的子类不写任何构造器，Java 会自动给你加一个无参构造器，里面自动调用 `super()`——但父类没有无参构造器时就报错了

```java
// 父类只有有参构造器
public class Animal {
    public Animal(String name) { ... }
}

// 错误：子类没写构造器，自动调用 super()，但父类没有无参构造器
public class Dog extends Animal {
    // 编译报错！
}

// 正确：显式调用父类有参构造器
public class Dog extends Animal {
    public Dog(String name) {
        super(name);  // 必须写
    }
}
```

> **记住**：看到父类只有有参构造器，子类就一定要写构造器并调用 `super(参数)`。

### super 关键字

`super` 指的是**父类**，和 `this`（当前对象）对应。

| 用法 | 说明 |
|------|------|
| `super(参数)` | 调用父类构造器，**必须放在子类构造器第一行** |
| `super.方法名()` | 调用父类的方法 |
| `super.属性名` | 访问父类的属性（前提是非 private） |

```java
public class Dog extends Animal {
    private String breed;  // 品种，Dog 独有的属性

    public Dog(String name, int age, String breed) {
        super(name, age);   // 先初始化父类部分
        this.breed = breed; // 再初始化自己的部分
    }
}
```

> **注意**：如果父类没有无参构造器，子类构造器**必须**显式调用 `super(参数)`。否则编译报错。

## 二、方法重写（Override）

子类可以**重新定义**父类的方法，这叫方法重写。

```java
public class Animal {
    public void eat() {
        System.out.println("动物在吃东西");
    }
}

public class Dog extends Animal {
    @Override  // 注解，标记这是重写（写错方法名会报错，推荐加上）
    public void eat() {
        System.out.println("狗在啃骨头");
    }
}

public class Cat extends Animal {
    @Override
    public void eat() {
        System.out.println("猫在吃鱼");
    }
}
```

```java
Dog dog = new Dog("旺财", 3);
dog.eat();  // 狗在啃骨头（执行的是 Dog 自己的 eat）
```

### 重写 vs 重载

| | 重写（Override） | 重载（Overload） |
|--|-----------------|------------------|
| 位置 | 子类和父类之间 | 同一个类中 |
| 方法名 | 相同 | 相同 |
| 参数列表 | **必须相同** | **必须不同** |
| 返回值 | 相同（或子类型） | 无要求 |
| 关键字 | @Override | 无 |

### 重写的规则

1. 方法名、参数列表必须和父类一致
2. 返回值类型必须相同（或是父类返回值的子类型）
3. 访问权限**不能更小**（父类是 public，子类不能改成 private）
4. 不能重写 `static` 方法、`final` 方法、`private` 方法

## 三、多态（Polymorphism）

多态是面向对象最强大的特性：**同一个方法调用，不同对象有不同的行为**。

### 向上转型

父类引用指向子类对象：

```java
Animal animal = new Dog("旺财", 3);  // 向上转型
animal.eat();  // 狗在啃骨头（执行的是 Dog 的 eat，不是 Animal 的）
```

编译看左边（Animal），运行看右边（Dog）：
- **编译时**：只能调用 Animal 中定义的方法（`animal.bark()` 会报错，因为 Animal 没有 bark）
- **运行时**：实际执行的是 Dog 的 eat 方法

### 多态的实际用途

```java
public class AnimalShop {
    // 参数类型是 Animal，但可以传入任何子类
    public static void feed(Animal animal) {
        System.out.println("喂食：");
        animal.eat();  // 传 Dog 就啃骨头，传 Cat 就吃鱼
    }

    public static void main(String[] args) {
        Dog dog = new Dog("旺财", 3);
        Cat cat = new Cat("小白", 2);

        feed(dog);  // 喂食：狗在啃骨头
        feed(cat);  // 喂食：猫在吃鱼
    }
}
```

好处：`feed` 方法不用为每种动物写一个版本，一个方法搞定所有子类。

### 向下转型

有时候需要把父类引用转回子类，用**强制转换**：

```java
Animal animal = new Dog("旺财", 3);

// 向下转型前先用 instanceof 判断
if (animal instanceof Dog) {
    Dog dog = (Dog) animal;  // 强制转换
    dog.bark();  // 现在可以调用 Dog 特有的方法了
}
```

> **重要**：不判断直接转，如果类型不对会抛 `ClassCastException`。所以**先 instanceof 再转**。

### Java 16+ instanceof 模式匹配

```java
if (animal instanceof Dog dog) {
    dog.bark();  // 判断 + 转换一步搞定
}
```

### 多态的执行过程

```java
Animal animal = new Dog("旺财", 3);
animal.eat();
```

1. 编译器看 `animal` 的类型是 `Animal`，检查 Animal 类有没有 `eat()` 方法 → 有，编译通过
2. 运行时，JVM 看 `animal` 实际指向的是 `Dog` 对象
3. 在 Dog 类中找 `eat()` → 找到了（重写了），执行 Dog 的 `eat()`
4. 如果 Dog 没重写 `eat()`，就往上找 Animal 的 `eat()`

这就是**动态绑定**：运行时才决定调用哪个方法。

## 四、final 关键字

| 用在哪 | 效果 |
|--------|------|
| `final class` | 不能被继承（如 String 类） |
| `final 方法` | 不能被子类重写 |
| `final 变量` | 只能赋值一次（常量） |

```java
final int MAX = 100;    // 常量，不能再改
// MAX = 200;           // 编译报错

final class String {}   // String 不能被继承
```
