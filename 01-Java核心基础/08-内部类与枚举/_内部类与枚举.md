# 内部类与枚举

## 一、内部类

内部类就是**定义在另一个类里面的类**。Java 有四种内部类，我们重点学前两种。

### 1. 成员内部类

定义在类的内部，和属性、方法平级：

```java
public class Outer {
    private String name = "外部类";

    // 成员内部类
    public class Inner {
        public void show() {
            // 内部类可以直接访问外部类的 private 属性
            System.out.println("访问外部类：" + name);
        }
    }
}
```

使用：
```java
Outer outer = new Outer();
Outer.Inner inner = outer.new Inner();  // 先有外部对象，才能创建内部对象
inner.show();  // 访问外部类：外部类
```

特点：
- 内部类可以直接访问外部类的**所有成员**（包括 private）
- 创建内部类对象必须**先有外部类对象**
- 实际开发中用得不多

### 2. 静态内部类

用 `static` 修饰的内部类，**不依赖外部类对象**：

```java
public class Outer {
    private static String staticName = "静态属性";
    private String name = "普通属性";

    public static class StaticInner {
        public void show() {
            System.out.println(staticName);  // 可以访问外部类的静态成员
            // System.out.println(name);     // 不能访问非静态成员！
        }
    }
}
```

使用：
```java
// 不需要外部类对象
Outer.StaticInner inner = new Outer.StaticInner();
inner.show();
```

特点：
- 只能访问外部类的**静态成员**
- 不需要外部类对象就能创建
- 实际开发中常用（比如 `Map.Entry`、Builder 模式）

### 3. 匿名内部类（重点！Lambda 的前身）

没有名字的类，**一次性使用**，写完就扔。通常用来快速实现一个接口或抽象类：

```java
public interface Greeting {
    void sayHello(String name);
}
```

正常写法——单独写一个实现类：
```java
public class ChineseGreeting implements Greeting {
    @Override
    public void sayHello(String name) {
        System.out.println("你好，" + name);
    }
}

Greeting g = new ChineseGreeting();
g.sayHello("张三");
```

匿名内部类写法——不用单独建类：
```java
Greeting g = new Greeting() {  // 注意：这不是 new 接口，是 new 了一个匿名实现类
    @Override
    public void sayHello(String name) {
        System.out.println("你好，" + name);
    }
};
g.sayHello("张三");  // 你好，张三
```

更常见的用法——直接作为参数传入方法：
```java
public static void greet(Greeting greeting, String name) {
    greeting.sayHello(name);
}

// 直接传一个匿名内部类
greet(new Greeting() {
    @Override
    public void sayHello(String name) {
        System.out.println("Hello, " + name);
    }
}, "张三");
```

> 匿名内部类写起来比较啰嗦，Java 8 引入了 **Lambda 表达式**来简化它（下一阶段会学）。

### 4. 局部内部类（了解即可）

定义在方法内部的类，作用域仅限该方法，实际开发几乎不用：

```java
public void test() {
    class LocalClass {
        void show() {
            System.out.println("局部内部类");
        }
    }
    new LocalClass().show();
}
```

### 内部类总结

| 类型 | 位置 | 能否访问外部类非静态成员 | 创建方式 | 使用频率 |
|------|------|------------------------|----------|----------|
| 成员内部类 | 类内部 | 能 | `outer.new Inner()` | 少 |
| 静态内部类 | 类内部（static） | 不能 | `new Outer.StaticInner()` | 较多 |
| 匿名内部类 | 任意位置 | 能 | `new 接口/父类() { ... }` | 多（Lambda 前身） |
| 局部内部类 | 方法内部 | 能 | 方法内 new | 几乎不用 |

## 二、枚举（Enum）

### 为什么需要枚举？

表示一组固定的常量，比如星期、季节、状态：

```java
// 用 int 常量？
public static final int SPRING = 1;
public static final int SUMMER = 2;
// 问题：传个 999 进来也不报错，没有约束
```

枚举就是解决这个问题：**限定只能用这几个值**。

### 基本语法

```java
public enum Season {
    SPRING, SUMMER, AUTUMN, WINTER
}
```

使用：
```java
Season s = Season.SPRING;
System.out.println(s);         // SPRING
System.out.println(s.name());  // SPRING（字符串）
System.out.println(s.ordinal()); // 0（序号，从 0 开始）
```

### 枚举配合 switch

```java
Season season = Season.SUMMER;

switch (season) {
    case SPRING -> System.out.println("春天");
    case SUMMER -> System.out.println("夏天");
    case AUTUMN -> System.out.println("秋天");
    case WINTER -> System.out.println("冬天");
}
```

### 枚举可以有属性和方法

```java
public enum Season {
    SPRING("春天", "万物复苏"),
    SUMMER("夏天", "烈日炎炎"),
    AUTUMN("秋天", "硕果累累"),
    WINTER("冬天", "白雪皑皑");

    private final String name;
    private final String description;

    // 构造器必须是 private（枚举不能被 new）
    Season(String name, String description) {
        this.name = name;
        this.description = description;
    }

    public String getName() {
        return name;
    }

    public String getDescription() {
        return description;
    }
}
```

```java
Season s = Season.SPRING;
System.out.println(s.getName());        // 春天
System.out.println(s.getDescription()); // 万物复苏
```

### 遍历所有枚举值

```java
for (Season s : Season.values()) {
    System.out.println(s.getName() + " - " + s.getDescription());
}
```

### 枚举的本质

枚举本质上是一个继承了 `java.lang.Enum` 的特殊类。每个枚举值就是一个**静态常量对象**。所以枚举天然是单例的、不可变的。

### 实际开发中枚举的常见用法

1. **状态码**：`OrderStatus.PAID`、`OrderStatus.SHIPPED`
2. **配置选项**：`LogLevel.DEBUG`、`LogLevel.ERROR`
3. **替代魔法数字**：用有意义的名字代替 1、2、3

- 在 Main 中用匿名内部类分别创建「加法」和「减法」两个实现

### 题目 2：枚举
- 定义一个枚举 `Weekday`，包含周一到周日
- 每个枚举值有一个中文名属性（如 "星期一"）
- 在 Main 中遍历所有枚举值，打印中文名
- 用 switch 判断某个 Weekday 是工作日还是休息日
