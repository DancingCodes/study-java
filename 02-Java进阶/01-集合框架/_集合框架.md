# 集合框架

## 一、为什么需要集合？

数组的局限：
- **长度固定**：创建后不能变，不够用了只能新建一个更大的数组再复制
- **操作不方便**：没有现成的增删改查方法

集合就是 Java 提供的**可变长度的容器**，自带各种操作方法。

## 二、集合体系总览

```
Collection（单列集合）
├── List（有序、可重复）
│   ├── ArrayList     ← 最常用，底层数组
│   ├── LinkedList    ← 底层链表
│   └── Vector        ← 线程安全，已过时
└── Set（无序、不重复）
    ├── HashSet       ← 最常用，底层 HashMap
    ├── LinkedHashSet ← 有序的 HashSet
    └── TreeSet       ← 自动排序

Map（双列集合，键值对）
├── HashMap           ← 最常用
├── LinkedHashMap     ← 有序的 HashMap
├── TreeMap           ← 按键排序
└── Hashtable         ← 线程安全，已过时
```

## 三、List — 有序可重复

### ArrayList（最常用）

底层是**数组**，查询快、增删慢（中间插入要移动元素）。

```java
import java.util.ArrayList;
import java.util.List;

List<String> list = new ArrayList<>();  // 泛型指定元素类型

// 添加
list.add("张三");
list.add("李四");
list.add("王五");
list.add(1, "赵六");  // 在下标 1 插入

// 获取
String name = list.get(0);  // "张三"
int size = list.size();     // 4

// 修改
list.set(0, "张三丰");  // 把下标 0 的元素改成 "张三丰"

// 删除
list.remove(0);          // 按下标删
list.remove("李四");     // 按元素删（删第一个匹配的）

// 判断
list.contains("王五");   // true
list.isEmpty();          // false

// 遍历方式 1：for 循环
for (int i = 0; i < list.size(); i++) {
    System.out.println(list.get(i));
}

// 遍历方式 2：增强 for（推荐）
for (String s : list) {
    System.out.println(s);
}

// 遍历方式 3：forEach + Lambda（Java 8+）
list.forEach(s -> System.out.println(s));
```

### ArrayList 的扩容机制

- 初始容量 10
- 容量不够时扩容为原来的 **1.5 倍**
- 所以频繁添加大量元素时，可以预设容量：`new ArrayList<>(1000)`

### LinkedList

底层是**双向链表**，增删快（只需改指针）、查询慢（要从头遍历）。

```java
import java.util.LinkedList;

LinkedList<String> list = new LinkedList<>();
list.add("张三");
list.addFirst("第一个");  // 头部添加
list.addLast("最后一个"); // 尾部添加
list.getFirst();          // 获取第一个
list.getLast();           // 获取最后一个
list.removeFirst();       // 删除第一个
list.removeLast();        // 删除最后一个
```

> LinkedList 还可以当**栈**（先进后出）和**队列**（先进先出）用。

### ArrayList vs LinkedList

| | ArrayList | LinkedList |
|--|-----------|------------|
| 底层结构 | 数组 | 双向链表 |
| 查询 | 快（下标直接访问） | 慢（从头遍历） |
| 增删 | 慢（要移动元素） | 快（改指针） |
| 使用场景 | 查询多、增删少 | 增删多、查询少 |
| 实际开发 | **95% 用这个** | 很少用 |

> 实际开发中几乎只用 ArrayList。因为现代 CPU 缓存对连续内存（数组）更友好，LinkedList 的理论优势在实践中很少体现。

## 四、Set — 无序不重复

### HashSet

不保证顺序，不允许重复元素：

```java
import java.util.HashSet;
import java.util.Set;

Set<String> set = new HashSet<>();
set.add("张三");
set.add("李四");
set.add("张三");  // 重复，添加失败（不报错，返回 false）

System.out.println(set.size());  // 2
System.out.println(set);         // [李四, 张三]（顺序不确定）

set.contains("张三");  // true
set.remove("张三");    // 删除

// 遍历（只能用增强 for 或 forEach，没有下标）
for (String s : set) {
    System.out.println(s);
}
```

### HashSet 去重原理

1. 先算 `hashCode()`，决定存放位置
2. 如果位置上已有元素，再用 `equals()` 比较内容
3. `hashCode` 相同且 `equals` 为 true → 判定为重复，不添加

> 所以自定义类放入 HashSet 时，**必须重写 hashCode() 和 equals()**，否则去重不生效。

```java
public class Student {
    private String name;
    private int age;

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        Student student = (Student) o;
        return age == student.age && name.equals(student.name);
    }

    @Override
    public int hashCode() {
        return Objects.hash(name, age);
    }
}
```

### LinkedHashSet

HashSet 的子类，**保持插入顺序**：

```java
Set<String> set = new LinkedHashSet<>();
set.add("C");
set.add("A");
set.add("B");
System.out.println(set);  // [C, A, B]（按插入顺序）
```

### TreeSet

自动**排序**的 Set：

```java
Set<Integer> set = new TreeSet<>();
set.add(5);
set.add(1);
set.add(3);
System.out.println(set);  // [1, 3, 5]（自动排序）
```

自定义类要放入 TreeSet，需要实现 `Comparable` 接口或传入 `Comparator`。

## 五、Map — 键值对

### HashMap（最常用）

存储 **key-value** 键值对，key 不能重复：

```java
import java.util.HashMap;
import java.util.Map;

Map<String, Integer> map = new HashMap<>();

// 添加 / 修改
map.put("张三", 90);
map.put("李四", 85);
map.put("王五", 70);
map.put("张三", 95);  // key 重复，value 被覆盖

// 获取
int score = map.get("张三");           // 95
int score2 = map.getOrDefault("赵六", 0);  // key 不存在返回默认值 0

// 判断
map.containsKey("张三");    // true
map.containsValue(95);      // true
map.size();                 // 3

// 删除
map.remove("王五");

// 遍历方式 1：遍历所有 key
for (String key : map.keySet()) {
    System.out.println(key + " = " + map.get(key));
}

// 遍历方式 2：遍历所有 entry（推荐，性能更好）
for (Map.Entry<String, Integer> entry : map.entrySet()) {
    System.out.println(entry.getKey() + " = " + entry.getValue());
}

// 遍历方式 3：forEach + Lambda
map.forEach((key, value) -> System.out.println(key + " = " + value));
```

### HashMap 底层原理（面试常问）

- JDK 8 之前：**数组 + 链表**
- JDK 8 之后：**数组 + 链表 + 红黑树**（链表长度 > 8 时转红黑树，提升查询性能）
- 默认容量 16，负载因子 0.75（元素数量达到容量的 75% 时扩容，扩容为 2 倍）

### HashMap 的 key 要求

- key 可以为 null（只能有一个 null key）
- 自定义类做 key 时，**必须重写 hashCode() 和 equals()**（和 HashSet 一样的原因）
- 实际开发中 key 通常用 String 或 Integer

### TreeMap

按 key **自动排序**：

```java
Map<String, Integer> map = new TreeMap<>();
map.put("C", 3);
map.put("A", 1);
map.put("B", 2);
System.out.println(map);  // {A=1, B=2, C=3}
```

## 六、集合选型指南

| 需求 | 选什么 |
|------|--------|
| 有序、可重复、按下标访问 | ArrayList |
| 不重复 | HashSet |
| 不重复 + 保持顺序 | LinkedHashSet |
| 不重复 + 排序 | TreeSet |
| 键值对 | HashMap |
| 键值对 + 按 key 排序 | TreeMap |

## 七、Collections 工具类

```java
import java.util.Collections;
import java.util.ArrayList;
import java.util.List;

List<Integer> list = new ArrayList<>();
list.add(5);
list.add(1);
list.add(3);

Collections.sort(list);      // 排序：[1, 3, 5]
Collections.reverse(list);   // 反转：[5, 3, 1]
Collections.shuffle(list);   // 随机打乱
int max = Collections.max(list);  // 最大值
int min = Collections.min(list);  // 最小值
```
