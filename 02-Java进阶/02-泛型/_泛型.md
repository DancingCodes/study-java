# 泛型

## 一、为什么需要泛型？

没有泛型之前，集合什么都能放：

```java
List list = new ArrayList();
list.add("hello");
list.add(123);       // 也能放，不报错
list.add(true);      // 也能放

String s = (String) list.get(1);  // 运行时 ClassCastException！
```

问题：
- 放进去不报错，取出来才爆炸
- 每次取出来都要**强制转换**，麻烦又容易出错

有了泛型，**在编译阶段就限定类型**：

```java
List<String> list = new ArrayList<>();
list.add("hello");
list.add(123);     // 编译报错！直接拦住

String s = list.get(0);  // 不用强转
```

泛型的好处：
1. **编译期检查类型**，把错误提前到编译阶段
2. **不用强制转换**，代码更干净

## 二、泛型类

定义一个类时，用 `<T>` 表示一个占位类型，使用时再指定具体类型：

```java
// T 是类型参数，随便取名，约定用大写字母
// T = Type, E = Element, K = Key, V = Value
public class Box<T> {
    private T content;

    public void put(T content) {
        this.content = content;
    }

    public T get() {
        return content;
    }
}
```

使用：
```java
Box<String> strBox = new Box<>();
strBox.put("hello");
String s = strBox.get();  // 不用强转

Box<Integer> intBox = new Box<>();
intBox.put(123);
int num = intBox.get();

// 同一个类，不同的类型参数，完全复用
```

### 多个类型参数

```java
public class Pair<K, V> {
    private K key;
    private V value;

    public Pair(K key, V value) {
        this.key = key;
        this.value = value;
    }

    public K getKey() { return key; }
    public V getValue() { return value; }
}

Pair<String, Integer> pair = new Pair<>("年龄", 18);
pair.getKey();    // "年龄"
pair.getValue();  // 18
```

## 三、泛型方法

不一定整个类都是泛型，也可以只在某个方法上用泛型：

```java
public class Utils {
    // <T> 声明类型参数，写在返回值前面
    public static <T> void printArray(T[] arr) {
        for (T item : arr) {
            System.out.print(item + " ");
        }
        System.out.println();
    }
}

// 调用时 Java 自动推断类型
Utils.printArray(new String[]{"a", "b", "c"});  // a b c
Utils.printArray(new Integer[]{1, 2, 3});        // 1 2 3
```

### 泛型方法 vs 泛型类

| | 泛型类 | 泛型方法 |
|--|--------|----------|
| 声明位置 | 类名后 `class Box<T>` | 方法返回值前 `<T> void print(T t)` |
| 作用范围 | 整个类 | 仅该方法 |
| 使用场景 | 类的多个方法都用同一个类型 | 只有一个方法需要泛型 |

## 四、泛型接口

```java
public interface Converter<F, T> {
    T convert(F from);
}

// 实现时指定具体类型
public class StringToInteger implements Converter<String, Integer> {
    @Override
    public Integer convert(String from) {
        return Integer.parseInt(from);
    }
}

Converter<String, Integer> c = new StringToInteger();
int num = c.convert("123");  // 123
```

## 五、类型通配符

### 问题引入

```java
public static void printList(List<Object> list) {
    for (Object o : list) {
        System.out.println(o);
    }
}

List<String> names = new ArrayList<>();
printList(names);  // 编译报错！List<String> 不是 List<Object> 的子类
```

泛型没有继承关系：`List<String>` 和 `List<Object>` 是**完全不同的类型**。

### `?` 通配符

用 `?` 表示「任意类型」：

```java
public static void printList(List<?> list) {
    for (Object o : list) {
        System.out.println(o);
    }
}

printList(names);  // OK！
```

### 上界通配符 `<? extends T>`

限定类型是 T 或 T 的子类（**只读**）：

```java
// 只接受 Number 或其子类（Integer, Double 等）
public static double sum(List<? extends Number> list) {
    double total = 0;
    for (Number num : list) {
        total += num.doubleValue();
    }
    return total;
}

List<Integer> intList = List.of(1, 2, 3);
List<Double> doubleList = List.of(1.1, 2.2);

sum(intList);     // OK
sum(doubleList);  // OK
```

> `extends` 通配符的集合**不能添加元素**（只能读），因为编译器不知道具体是哪个子类。

### 下界通配符 `<? super T>`

限定类型是 T 或 T 的父类（**只写**）：

```java
// 只接受 Integer 或其父类（Number, Object）
public static void addNumbers(List<? super Integer> list) {
    list.add(1);
    list.add(2);
    list.add(3);
}

List<Number> numList = new ArrayList<>();
addNumbers(numList);  // OK
```

### PECS 原则（记忆口诀）

- **P**roducer **E**xtends：如果只**读取**数据，用 `<? extends T>`
- **C**onsumer **S**uper：如果只**写入**数据，用 `<? super T>`

## 六、类型擦除

泛型只在**编译阶段**有效，编译完成后泛型信息会被**擦除**：

```java
List<String> strList = new ArrayList<>();
List<Integer> intList = new ArrayList<>();

// 运行时它们是同一个类型！
System.out.println(strList.getClass() == intList.getClass());  // true
```

编译后 `List<String>` 和 `List<Integer>` 都变成了 `List`（原始类型）。这就是为什么：
- 不能 `new T()`（运行时不知道 T 是什么）
- 不能 `instanceof List<String>`（运行时没有泛型信息）
- 不能创建泛型数组 `new T[10]`

了解即可，实际写代码时很少碰到这些限制。

## 练习题

### 题目 1：泛型类
写一个 `Result<T>` 类，模拟接口返回结果：
- 属性：`boolean success`、`String message`、`T data`
- 有参构造器
- getter 方法
- 在 Main 中分别创建 `Result<String>` 和 `Result<Integer>` 测试

### 题目 2：泛型方法
写一个泛型方法 `<T> T getFirst(List<T> list)`：
- 返回列表的第一个元素
- 如果列表为空，返回 null
- 分别用 `List<String>` 和 `List<Integer>` 测试

### 题目 3：通配符
写一个方法 `printAll(List<?> list)`：
- 遍历打印列表中所有元素
- 分别传入 `List<String>`、`List<Integer>`、`List<Double>` 测试
