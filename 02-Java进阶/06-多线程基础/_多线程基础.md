# 多线程基础

## 一、什么是线程？

**进程**：运行中的程序，比如你打开了微信，微信就是一个进程。

**线程**：进程中的一个执行单元。一个进程可以有多个线程，它们共享进程的内存，同时执行不同的任务。

> 比喻：进程是一个工厂，线程是工厂里的工人。一个工厂可以有多个工人同时干活。

Java 程序的 `main()` 方法就运行在**主线程**中。

## 二、为什么需要多线程？

单线程就像只有一个收银员的超市——所有顾客排一队，一个一个结账，很慢。

多线程就是开多个收银台，同时服务多个顾客：
- 下载文件时不卡住界面
- 服务器同时处理多个用户请求
- 批量处理数据时加速

## 三、创建线程的三种方式

### 方式一：继承 Thread 类

```java
public class MyThread extends Thread {
    @Override
    public void run() {
        for (int i = 0; i < 5; i++) {
            System.out.println(getName() + " 执行：" + i);
        }
    }
}

// 使用
MyThread t = new MyThread();
t.start(); // 启动线程，不能直接调用 run()
```

> 注意：调用 `start()` 才是启动新线程，调用 `run()` 只是普通方法调用，不会创建新线程。

### 方式二：实现 Runnable 接口（推荐）

```java
public class MyRunnable implements Runnable {
    @Override
    public void run() {
        for (int i = 0; i < 5; i++) {
            System.out.println(Thread.currentThread().getName() + " 执行：" + i);
        }
    }
}

// 使用
Thread t = new Thread(new MyRunnable(), "工人A");
t.start();
```

**为什么推荐 Runnable？**
- Java 是单继承，继承了 Thread 就不能继承别的类
- Runnable 把任务和线程分离，更灵活
- 可以用 Lambda 简化

### 方式三：Lambda 简化（最简洁）

Runnable 是函数式接口（只有一个抽象方法），可以用 Lambda：

```java
Thread t = new Thread(() -> {
    for (int i = 0; i < 5; i++) {
        System.out.println(Thread.currentThread().getName() + " 执行：" + i);
    }
}, "工人B");
t.start();
```

## 四、Thread 常用方法

| 方法 | 说明 |
|------|------|
| `start()` | 启动线程 |
| `run()` | 线程要执行的任务（不要直接调用） |
| `getName()` | 获取线程名 |
| `setName(String)` | 设置线程名 |
| `Thread.currentThread()` | 获取当前正在执行的线程对象 |
| `Thread.sleep(毫秒)` | 让当前线程暂停指定时间 |
| `join()` | 等待该线程执行完毕 |
| `isAlive()` | 判断线程是否还活着 |

### sleep 示例

```java
Thread t = new Thread(() -> {
    for (int i = 1; i <= 3; i++) {
        System.out.println("倒计时：" + i);
        try {
            Thread.sleep(1000); // 暂停 1 秒
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
    }
});
t.start();
```

### join 示例

```java
Thread t = new Thread(() -> {
    System.out.println("子线程开始");
    try { Thread.sleep(2000); } catch (InterruptedException e) {}
    System.out.println("子线程结束");
});
t.start();
t.join(); // 主线程等子线程执行完
System.out.println("主线程继续");
```

输出顺序一定是：子线程开始 → 子线程结束 → 主线程继续

## 五、线程安全问题

多个线程同时操作共享数据时，会出问题：

```java
public class Counter {
    private int count = 0;
    
    public void add() {
        count++; // 这一步不是原子操作！
    }
    
    public int getCount() {
        return count;
    }
}
```

`count++` 实际上分三步：读取 count → 加 1 → 写回 count。两个线程同时执行时可能：
1. 线程A 读到 count = 0
2. 线程B 也读到 count = 0
3. 线程A 写回 count = 1
4. 线程B 写回 count = 1（本应是 2！）

## 六、synchronized 解决线程安全

`synchronized` 就像给代码加了一把锁，同一时间只有一个线程能进入。

### 同步方法

```java
public class Counter {
    private int count = 0;
    
    // 加了 synchronized，同一时间只有一个线程能执行
    public synchronized void add() {
        count++;
    }
    
    public int getCount() {
        return count;
    }
}
```

### 同步代码块

```java
public void add() {
    synchronized (this) { // 锁对象是 this
        count++;
    }
}
```

> 同步方法锁的是整个方法，同步代码块可以只锁关键部分，粒度更细，性能更好。

## 七、线程池（重点）

每次 `new Thread()` 创建线程开销大，用完就销毁浪费资源。**线程池**预先创建一批线程，重复使用：

> 比喻：不是每来一个快递就招一个快递员，而是公司养着固定几个快递员，有单子就分配。

### 使用 ExecutorService

```java
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;

// 创建固定大小的线程池
ExecutorService pool = Executors.newFixedThreadPool(3);

// 提交任务
pool.submit(() -> System.out.println(Thread.currentThread().getName() + " 任务1"));
pool.submit(() -> System.out.println(Thread.currentThread().getName() + " 任务2"));
pool.submit(() -> System.out.println(Thread.currentThread().getName() + " 任务3"));
pool.submit(() -> System.out.println(Thread.currentThread().getName() + " 任务4"));

// 用完关闭
pool.shutdown();
```

4 个任务，3 个线程，线程池会自动分配，某个线程做完一个任务后接着做下一个。

### 常见线程池类型

| 方法 | 说明 |
|------|------|
| `newFixedThreadPool(n)` | 固定 n 个线程 |
| `newCachedThreadPool()` | 按需创建，空闲 60 秒回收 |
| `newSingleThreadExecutor()` | 单线程，保证任务按顺序执行 |

实际开发中最常用的是 `newFixedThreadPool`。
