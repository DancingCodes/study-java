# 网络编程基础

## 一、HTTP 协议

### 什么是 HTTP？

HTTP（HyperText Transfer Protocol）是浏览器和服务器之间通信的规则。你打开网页、调用接口，底层都是 HTTP。

> 比喻：HTTP 就像写信的格式 —— 信封上写什么、信里怎么写、回信怎么写，双方都遵守同一套规则。

### 请求和响应

一次 HTTP 通信分两步：
1. **客户端发请求**（Request）：我要什么数据
2. **服务器返响应**（Response）：给你数据

### HTTP 请求的组成

```
GET /api/users?id=1 HTTP/1.1     ← 请求行（方法 + 路径 + 版本）
Host: www.example.com             ← 请求头
Content-Type: application/json
                                  ← 空行
{"name": "Tom"}                   ← 请求体（GET 一般没有）
```

### 常用请求方法

| 方法 | 用途 | 有请求体 |
|------|------|----------|
| GET | 获取数据 | 无 |
| POST | 提交/创建数据 | 有 |
| PUT | 更新数据（全量） | 有 |
| DELETE | 删除数据 | 无 |

> 以后用 Spring Boot 写接口时，每个接口都要选用合适的方法。

### HTTP 响应的组成

```
HTTP/1.1 200 OK                  ← 状态行（版本 + 状态码 + 描述）
Content-Type: application/json   ← 响应头
                                 ← 空行
{"id": 1, "name": "Tom"}         ← 响应体
```

### 常见状态码

| 状态码 | 含义 | 说明 |
|--------|------|------|
| 200 | OK | 请求成功 |
| 201 | Created | 创建成功 |
| 400 | Bad Request | 请求参数有误 |
| 401 | Unauthorized | 未认证（没登录） |
| 403 | Forbidden | 没权限 |
| 404 | Not Found | 资源不存在 |
| 500 | Internal Server Error | 服务器内部错误 |

记住规律：
- **2xx**：成功
- **4xx**：客户端的错
- **5xx**：服务器的错

## 二、Socket 基本概念

### 什么是 Socket？

Socket（套接字）是网络通信的端点。两台电脑通信，各自创建一个 Socket，通过 Socket 收发数据。

> 比喻：Socket 就像电话。打电话需要双方各拿一个电话，拨号连接后就能说话。

HTTP 底层也是基于 Socket 实现的，但 Socket 更底层、更灵活。

### TCP 和 UDP

| | TCP | UDP |
|-|-----|-----|
| 连接 | 先连接再通信（三次握手） | 不需要连接，直接发 |
| 可靠性 | 保证数据到达且有序 | 不保证 |
| 速度 | 稍慢 | 快 |
| 场景 | 网页、文件传输、接口调用 | 视频通话、游戏、直播 |

后端开发主要用 TCP。

## 三、Java Socket 编程（TCP）

### 通信流程

```
服务器                        客户端
1. 创建 ServerSocket          
2. 等待连接（accept）          
                              3. 创建 Socket，连接服务器
4. 获得连接，创建 Socket       
5. 通过流收发数据              6. 通过流收发数据
7. 关闭连接                   8. 关闭连接
```

### 服务器端

```java
import java.io.*;
import java.net.ServerSocket;
import java.net.Socket;

public class Server {
    public static void main(String[] args) throws IOException {
        // 1. 创建 ServerSocket，监听 8888 端口
        ServerSocket serverSocket = new ServerSocket(8888);
        System.out.println("服务器启动，等待连接...");

        // 2. 等待客户端连接（会阻塞，直到有客户端连接）
        Socket socket = serverSocket.accept();
        System.out.println("客户端已连接：" + socket.getInetAddress());

        // 3. 获取输入流，读客户端发来的数据
        BufferedReader reader = new BufferedReader(
                new InputStreamReader(socket.getInputStream()));
        String message = reader.readLine();
        System.out.println("收到消息：" + message);

        // 4. 获取输出流，给客户端回消息
        PrintWriter writer = new PrintWriter(
                new OutputStreamWriter(socket.getOutputStream()), true);
        writer.println("服务器收到：" + message);

        // 5. 关闭
        socket.close();
        serverSocket.close();
    }
}
```

### 客户端

```java
import java.io.*;
import java.net.Socket;

public class Client {
    public static void main(String[] args) throws IOException {
        // 1. 创建 Socket，连接服务器
        Socket socket = new Socket("localhost", 8888);
        System.out.println("已连接服务器");

        // 2. 发送消息
        PrintWriter writer = new PrintWriter(
                new OutputStreamWriter(socket.getOutputStream()), true);
        writer.println("你好，服务器！");

        // 3. 接收服务器回复
        BufferedReader reader = new BufferedReader(
                new InputStreamReader(socket.getInputStream()));
        String response = reader.readLine();
        System.out.println("服务器回复：" + response);

        // 4. 关闭
        socket.close();
    }
}
```

**运行步骤：**
1. 先启动 Server（它会等待连接）
2. 再启动 Client（连接后发送消息）
3. Server 收到消息并回复，Client 打印回复

## 四、Java 发送 HTTP 请求

Java 11 引入了 `HttpClient`，可以方便地发送 HTTP 请求：

```java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class HttpDemo {
    public static void main(String[] args) throws Exception {
        // 创建 HttpClient
        HttpClient client = HttpClient.newHttpClient();

        // 构建 GET 请求
        HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create("https://httpbin.org/get"))
                .GET()
                .build();

        // 发送请求，获取响应
        HttpResponse<String> response = client.send(
                request, HttpResponse.BodyHandlers.ofString());

        // 打印状态码和响应体
        System.out.println("状态码：" + response.statusCode());
        System.out.println("响应体：" + response.body());
    }
}
```

## 五、总结

| 概念 | 说明 | 后面用在哪 |
|------|------|------------|
| HTTP 协议 | 浏览器与服务器的通信规则 | Spring Boot 写接口 |
| 请求方法 | GET/POST/PUT/DELETE | RESTful API 设计 |
| 状态码 | 200/404/500 等 | 接口返回和错误处理 |
| Socket | 网络通信的底层端点 | 理解服务器原理 |
| TCP | 可靠传输协议 | 所有后端通信的基础 |

> 这一课重在**理解概念**，以后学 Spring Boot 时不需要手写 Socket，框架会帮你处理。
