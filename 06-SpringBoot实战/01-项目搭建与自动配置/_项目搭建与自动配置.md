# Spring Boot 项目搭建与自动配置

## 一、Java Web 开发演变史

在学 Spring Boot 之前，先了解 Java 后端开发是怎么一步步演变过来的，这样你就能理解为什么现在用 Spring Boot。

### 1.1 Servlet 时代（2000 年代初）

Java 最早做 Web 开发用的是 **Servlet**，手写每一个 HTTP 请求的处理：

```java
// 一个 Servlet 处理一个 URL
public class UserServlet extends HttpServlet {
    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws IOException {
        resp.setContentType("text/html");
        resp.getWriter().write("<h1>用户列表</h1>");
    }
}
```

还需要在 `web.xml` 里手动配置 URL 映射：
```xml
<servlet-mapping>
    <servlet-name>userServlet</servlet-name>
    <url-pattern>/users</url-pattern>
</servlet-mapping>
```

**问题**：每个 URL 一个 Servlet 类，配置繁琐，HTML 和 Java 混在一起。

### 1.2 JSP 时代（2000 年代中）

在 HTML 里嵌入 Java 代码：

```jsp
<%
    List<User> users = userDao.findAll();
    for (User u : users) {
%>
    <p><%= u.getName() %></p>
<% } %>
```

**问题**：Java 代码和 HTML 混在一起，维护噩梦。就像早期 PHP 那样。

### 1.3 SSH/SSM 时代（2010 年前后）

引入 MVC 分层架构，前后端逻辑分离：

- **SSH** = Struts2 + Spring + Hibernate（老一代）
- **SSM** = Spring MVC + Spring + MyBatis（主流，现在很多公司还在用）

Spring MVC 用注解处理请求，比 Servlet 方便多了：

```java
@Controller
public class UserController {
    @RequestMapping("/users")
    public String list(Model model) {
        model.addAttribute("users", userService.findAll());
        return "userList";  // 返回 JSP 页面名
    }
}
```

**但还是有问题**：
- 需要大量 XML 配置（Spring 配置、MVC 配置、事务配置...）
- 需要手动部署到外部 Tomcat
- 依赖版本要自己管理，容易冲突

### 1.4 Spring Boot 时代（2014 至今）

Spring Boot 的出现彻底解决了上面的问题：
- **零 XML 配置** — 注解 + yml 搞定
- **内嵌 Tomcat** — 直接运行 main 方法
- **自动配置** — 引入 starter 就自动配好
- **前后端分离** — 后端只提供 JSON 接口，前端用 Vue/React

### 1.5 演变总结

```
Servlet（手写一切）
  → JSP（HTML 里写 Java）
    → Spring MVC（MVC 分层，但配置多）
      → Spring Boot（自动配置，开箱即用）← 你现在学的
```

现在的主流：**Spring Boot + Vue/React 前后端分离**。后端只写 API 接口返回 JSON，前端负责页面。这也是你最终要掌握的模式。

## 二、什么是 Spring Boot

Spring Boot = **Spring + 自动配置 + 内嵌服务器**。

之前学的 Spring 项目，你需要手动配置很多东西（AppConfig、ComponentScan、依赖版本管理等）。Spring Boot 把这些全自动化了：

| Spring | Spring Boot |
|--------|-------------|
| 手动配置 Bean | 自动配置 |
| 手动管理依赖版本 | starter 统一管理 |
| 需要外部 Tomcat | 内嵌 Tomcat，直接运行 |
| 配置 XML 或 Java Config | application.yml 搞定 |

类比：Spring 是手动挡，Spring Boot 是自动挡。功能一样，但开起来省心多了。

## 三、创建 Spring Boot 项目

### 2.1 使用 Spring Initializr

最推荐的方式：

1. IDEA → File → New → Project → **Spring Initializr**
2. 填写信息：
   - Group：`com.study`
   - Artifact：`springboot-demo`

## 三、启动类 — @SpringBootApplication

```java
@SpringBootApplication
public class SpringbootDemoApplication {
    public static void main(String[] args) {
        SpringApplication.run(SpringbootDemoApplication.class, args);
    }
}
```

`@SpringBootApplication` 是一个组合注解，拆开看：

```java
@SpringBootApplication
  = @Configuration       // 这是一个配置类
  + @ComponentScan       // 自动扫描当前包及子包
  + @EnableAutoConfiguration  // 开启自动配置（核心！）
```

所以你之前手写的 `AppConfig` + `@ComponentScan` + `@EnableAspectJAutoProxy` 全都不需要了，一个 `@SpringBootApplication` 搞定。

## 四、自动配置原理（了解）

Spring Boot 是怎么做到自动配置的？

1. 你在 pom.xml 引入了 `spring-boot-starter-web`
2. Spring Boot 扫描所有 starter 里的自动配置类
3. 根据你引入的依赖，自动创建需要的 Bean（如 Tomcat、DispatcherServlet 等）
4. 你可以通过 `application.yml` 覆盖默认配置

```
引入 starter-web → 自动配置 Tomcat + SpringMVC
引入 starter-data-redis → 自动配置 Redis 连接
引入 starter-data-jpa → 自动配置数据库连接
```

**你只管引依赖，Spring Boot 自动帮你配好。**

## 五、Starter 机制

starter 就是一组预定义的依赖集合，引入一个 starter 就能获得一整套功能：

| Starter | 包含什么 | 用途 |
|---------|---------|------|
| `spring-boot-starter-web` | SpringMVC + Tomcat + Jackson | Web 开发 |
| `spring-boot-starter-data-jpa` | JPA + Hibernate | 数据库 ORM |
| `spring-boot-starter-data-redis` | Jedis/Lettuce | Redis |
| `spring-boot-starter-test` | JUnit5 + Mockito | 测试 |
| `spring-boot-starter-validation` | Hibernate Validator | 参数校验 |

类比 npm：`starter-web` 就像一个大包，帮你装好了 express + body-parser + cors 等一堆相关依赖。

## 六、pom.xml 解析

```xml
<?xml version="1.0" encoding="UTF-8"?>
<project ...>
    <modelVersion>4.0.0</modelVersion>

    <!-- 继承 Spring Boot 父项目（统一管理依赖版本） -->
    <parent>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-parent</artifactId>
        <version>3.2.3</version>
    </parent>

    <groupId>com.study</groupId>
    <artifactId>springboot-demo</artifactId>
    <version>1.0.0</version>

    <properties>
        <java.version>17</java.version>
    </properties>

    <dependencies>
        <!-- Web 开发 -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-web</artifactId>
            <!-- 不需要写版本号！parent 统一管理 -->
        </dependency>

        <!-- Lombok -->
        <dependency>
            <groupId>org.projectlombok</groupId>
            <artifactId>lombok</artifactId>
            <scope>provided</scope>
        </dependency>

        <!-- 测试 -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-test</artifactId>
            <scope>test</scope>
        </dependency>
    </dependencies>

    <build>
        <plugins>
            <plugin>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-maven-plugin</artifactId>
            </plugin>
        </plugins>
    </build>
</project>
```

注意：有了 `<parent>` 之后，依赖**不需要写版本号**，parent 已经帮你统一管理了。

## 七、配置文件 — application.yml

Spring Boot 用 `application.yml`（或 `application.properties`）做配置，推荐用 yml 格式，更清晰：

```yaml
# 服务端口（默认 8080）
server:
  port: 8080

# 应用名
spring:
  application:
    name: springboot-demo

# 数据库（后面用到）
  datasource:
    url: jdbc:mysql://localhost:3306/study_db?useSSL=false&serverTimezone=Asia/Shanghai
    username: root
    password: 123456
    driver-class-name: com.mysql.cj.jdbc.Driver
```

**yml 格式注意**：
- 用缩进表示层级（2 个空格），不能用 Tab
- 冒号后面必须有空格：`port: 8080`（不是 `port:8080`）
- 字符串不需要引号（特殊字符除外）

### 练习 2：写一个 Hello 接口

创建 `controller/HelloController.java`：

```java
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class HelloController {

    @GetMapping("/hello")
    public String hello() {
        return "Hello, Spring Boot!";
    }
}
```

启动后浏览器访问 `http://localhost:8080/hello`，看到返回 `Hello, Spring Boot!` 就成功了。
