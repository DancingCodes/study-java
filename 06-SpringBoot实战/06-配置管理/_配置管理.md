# 配置管理

## 一、为什么需要配置管理

到目前为止，我们的数据库密码、端口号都直接写在 `application.yml` 里。但实际开发中会有多个环境：

- **开发环境（dev）**：本地数据库，debug 日志，端口 8080
- **测试环境（test）**：测试服务器数据库，info 日志
- **生产环境（prod）**：正式服务器数据库，warn 日志，端口 80

每次切换环境都手动改配置？太容易出错了。Spring Boot 提供了多环境配置方案。

## 二、多环境配置

### 2.1 配置文件拆分

一个主配置文件 + 每个环境一个配置文件：

```
resources/
├── application.yml         ← 主配置（公共配置 + 指定激活哪个环境）
├── application-dev.yml     ← 开发环境
├── application-test.yml    ← 测试环境
└── application-prod.yml    ← 生产环境
```

### 2.2 主配置文件

```yaml
# application.yml — 公共配置
spring:
  application:
    name: config-demo
  profiles:
    active: dev   # ← 激活哪个环境，改这一个值就行
```

### 2.3 各环境配置

```yaml
# application-dev.yml — 开发环境
server:
  port: 8080

spring:
  datasource:
    url: jdbc:mysql://localhost:3306/study_db?useSSL=false&serverTimezone=Asia/Shanghai
    username: root
    password: 123456
    driver-class-name: com.mysql.cj.jdbc.Driver
```

```yaml
# application-test.yml — 测试环境
server:
  port: 8081

spring:
  datasource:
    url: jdbc:mysql://test-server:3306/study_db?useSSL=false&serverTimezone=Asia/Shanghai
    username: test_user
    password: test_pwd
    driver-class-name: com.mysql.cj.jdbc.Driver
```

```yaml
# application-prod.yml — 生产环境
server:
  port: 80

spring:
  datasource:
    url: jdbc:mysql://prod-server:3306/study_db?useSSL=false&serverTimezone=Asia/Shanghai
    username: prod_user
    password: prod_pwd_encrypted
    driver-class-name: com.mysql.cj.jdbc.Driver
```

切换环境只需要改 `application.yml` 中的 `active: dev` → `active: prod`。

也可以启动时用命令行参数指定（不改文件）：
```bash
java -jar app.jar --spring.profiles.active=prod
```

## 三、@Value — 读取单个配置值

### 3.1 基本用法

在 `application.yml` 中自定义配置：
```yaml
app:
  name: 商品管理系统
  version: 1.0.0
  upload-dir: /data/uploads
```

在 Java 代码中用 `@Value` 读取：
```java
@RestController
public class AppController {

    @Value("${app.name}")
    private String appName;

    @Value("${app.version}")
    private String appVersion;

    @Value("${app.upload-dir}")
    private String uploadDir;

    @GetMapping("/app/info")
    public Result<String> info() {
        return Result.success(appName + " v" + appVersion);
    }
}
```

### 3.2 设置默认值

```java
@Value("${app.description:这是一个学习项目}")  // 冒号后面是默认值
private String description;

@Value("${app.max-upload-size:10485760}")  // 默认 10MB
private Long maxUploadSize;
```

如果 yml 中没有配置这个 key，就用默认值，不会报错。

## 四、@ConfigurationProperties — 批量绑定配置

`@Value` 一个一个读太麻烦了，`@ConfigurationProperties` 可以把一组配置自动映射到一个 Java 对象：

### 4.1 定义配置类

```java
import lombok.Data;
import org.springframework.boot.context.properties.ConfigurationProperties;
import org.springframework.stereotype.Component;

@Data
@Component
@ConfigurationProperties(prefix = "app")
public class AppProperties {
    private String name;          // 对应 app.name
    private String version;       // 对应 app.version
    private String uploadDir;     // 对应 app.upload-dir（自动转驼峰）
    private Long maxUploadSize;   // 对应 app.max-upload-size
}
```

### 4.2 对应的 yml 配置

```yaml
app:
  name: 商品管理系统
  version: 1.0.0
  upload-dir: /data/uploads
  max-upload-size: 10485760
```

### 4.3 使用配置类

```java
@RestController
public class AppController {

    @Autowired
    private AppProperties appProperties;

    @GetMapping("/app/info")
    public Result<AppProperties> info() {
        return Result.success(appProperties);
    }
}
```

返回：
```json
{
    "code": 200,
    "message": "操作成功",
    "data": {
        "name": "商品管理系统",
        "version": "1.0.0",
        "uploadDir": "/data/uploads",
        "maxUploadSize": 10485760
    }
}
```

### 4.4 @Value vs @ConfigurationProperties

| | @Value | @ConfigurationProperties |
|---|--------|-------------------------|
| 绑定方式 | 一个一个字段 | 按前缀批量绑定 |
| 类型安全 | 弱（字符串 key） | 强（Java 类型） |
| 适合场景 | 读 1-2 个值 | 一组相关配置 |
| 松散绑定 | 不支持 | 支持（upload-dir → uploadDir） |

简单记：少量配置用 `@Value`，一组配置用 `@ConfigurationProperties`。

## 五、yml 配置的数据类型

```yaml
app:
  name: 商品管理系统          # String
  version: 1.0.0             # String
  port: 8080                 # Integer
  price: 99.99               # Double
  enabled: true              # Boolean
  tags:                      # List<String>
    - 电商
    - 后台管理
  admin:                     # 嵌套对象
    username: admin
    email: admin@example.com
```

对应 Java 类：
```java
@Data
@Component
@ConfigurationProperties(prefix = "app")
public class AppProperties {
    private String name;
    private String version;
    private Integer port;
    private Double price;
    private Boolean enabled;
    private List<String> tags;
    private Admin admin;

    @Data
    public static class Admin {
        private String username;
        private String email;
    }
}
```

## 六、配置优先级

Spring Boot 配置的优先级从高到低：

```
1. 命令行参数        --server.port=9090
2. 环境变量          SERVER_PORT=9090
3. application-{profile}.yml
4. application.yml
5. 默认值
```

高优先级覆盖低优先级。所以命令行参数可以覆盖一切，生产部署时很有用。

## 练习

### 练习 1：多环境配置

1. 创建三个环境配置文件：`application-dev.yml`、`application-test.yml`、`application-prod.yml`
2. 各环境端口不同：dev=8080、test=8081、prod=80
3. 各环境数据库不同（用不同的数据库名模拟即可）
4. 在主配置 `application.yml` 中激活 dev 环境
5. 启动项目，确认端口是 8080

### 练习 2：自定义配置

1. 在 yml 中添加一组 `app` 开头的自定义配置（name、version、uploadDir、maxUploadSize）
2. 创建 `config/AppProperties.java`，用 `@ConfigurationProperties(prefix = "app")` 绑定
3. 创建 `controller/AppController.java`，提供 `GET /app/info` 接口返回配置信息
4. 启动后访问 `http://localhost:8080/app/info` 验证
