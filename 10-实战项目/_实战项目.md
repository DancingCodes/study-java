# 阶段十：实战项目 — 通用后台管理系统

## 项目概述

开发一套**通用后台管理系统**（类似若依 RuoYi），前后端分离，覆盖企业级后台的核心功能。

- **后端**：Spring Boot 3 + MyBatis Plus + MySQL + Redis + Spring Security + JWT
- **前端**：Vue 3 + Element Plus + Vite + Pinia + Vue Router
- **部署**：Docker + Docker Compose + Nginx

## 功能模块

### 一、系统管理

| 模块 | 功能 | 关键技术点 |
|------|------|------------|
| **用户管理** | 用户增删改查、重置密码、分配角色、导入导出 | MyBatis Plus 分页、条件构造器 |
| **角色管理** | 角色增删改查、分配菜单权限、分配数据权限 | RBAC 模型、中间表 |
| **菜单管理** | 树形菜单、目录/菜单/按钮三级、动态路由 | 递归构建树、前端动态路由 |
| **部门管理** | 树形部门结构、上下级关系 | 树形数据、递归查询 |
| **字典管理** | 字典类型 + 字典数据、前端下拉选项统一管理 | Redis 缓存字典 |

### 二、系统监控

| 模块 | 功能 | 关键技术点 |
|------|------|------------|
| **操作日志** | 记录增删改操作、操作人/时间/IP/请求参数 | AOP + 自定义注解 @Log |
| **登录日志** | 登录记录、登录 IP、登录状态 | 登录事件监听 |
| **定时任务** | 任务管理（增删改查）、手动执行、暂停/恢复、执行日志 | @Scheduled + 动态调度 |

### 三、业务功能

| 模块 | 功能 | 关键技术点 |
|------|------|------------|
| **通知公告** | 发布公告、通知类型、已读/未读、富文本编辑 | 关联用户已读表 |
| **文件管理** | 图片/文件上传、预览、删除 | 本地存储 + OSS 可切换 |
| **数据看板** | 首页统计（用户数、今日登录、操作量）、图表展示 | SQL 聚合、ECharts |

## 数据库设计

### 核心表

```
用户相关：
  sys_user          — 用户表
  sys_role          — 角色表
  sys_menu          — 菜单表（目录/菜单/按钮）
  sys_dept          — 部门表
  sys_user_role     — 用户-角色关联表
  sys_role_menu     — 角色-菜单关联表

字典：
  sys_dict_type     — 字典类型表
  sys_dict_data     — 字典数据表

日志：
  sys_oper_log      — 操作日志表
  sys_login_log     — 登录日志表

定时任务：
  sys_job           — 定时任务表
  sys_job_log       — 任务执行日志表

通知：
  sys_notice        — 通知公告表
  sys_notice_read   — 通知已读记录表

文件：
  sys_file          — 文件记录表
```

### 权限模型（RBAC）

```
用户 ←多对多→ 角色 ←多对多→ 菜单（含按钮权限）

例如：
  用户「张三」 → 角色「管理员」 → 菜单「用户管理」+ 按钮「新增/删除/导出」
  用户「李四」 → 角色「普通用户」 → 菜单「通知公告」（只读）
```

## 技术要点说明

### 动态路由
用户登录后，后端返回该用户有权访问的菜单列表，前端据此动态生成路由和侧边栏。不同角色看到的菜单不同。

### 按钮级权限
菜单表中 type=3 表示按钮，每个按钮有一个权限标识（如 `system:user:add`）。前端用 `v-if` 判断是否显示按钮，后端用 `@PreAuthorize` 拦截接口。

### 操作日志 AOP
自定义 `@Log("删除用户")` 注解，通过 AOP 切面自动记录操作人、操作时间、请求参数、执行结果。

### 动态定时任务
不用 `@Scheduled` 硬编码，而是将任务配置存数据库，通过 `ScheduledTaskRegistrar` 或 `TaskScheduler` 动态管理任务的增删和暂停恢复。

### 字典缓存
字典数据修改不频繁但查询频繁，启动时加载到 Redis，前端统一从接口获取字典渲染下拉框/标签。
